# Tradecraft - Agricultural Export Platform

Modern web platform for agricultural commodity trading and export services.

## 🌾 Overview

Tradecraft is a comprehensive platform designed for agricultural commodity export businesses, featuring product catalogs, service showcases, and international trade management tools.

## 🚀 Quick Start

```
npm install
npm start
npm run build
```

## 📦 Core Features

- Product catalog with filtering  
- Service portfolio display  
- Certificate management  
- Contact & inquiry system  
- Responsive design  

## 🎨 Technology

- React 18+
- React Router v6
- CSS Modules
- Font Awesome
- Material-UI
